⚙️ CONFIGURAÇÃO NECESSÁRIA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

IMPORTANTE! Você precisa configurar as localizações:

Arquivo: game/plugins/Game/config.yml

1. LOBBY LOCATION (onde jogadores aparecem)
   lobby-location:
     world: "world"
     x: 0
     y: 100
     z: 0
     yaw: 0
     pitch: 0

2. ARENA LOCATION (onde o jogo acontece)
   arena-location:
     world: "world"
     x: 100
     y: 100
     z: 100
     yaw: 0
     pitch: 0

COMO PEGAR COORDENADAS:
1. Entre no servidor
2. Vá para o local desejado
3. Pressione F3 (Java) ou veja coordenadas
4. Copie X, Y, Z
5. Cole no config.yml
