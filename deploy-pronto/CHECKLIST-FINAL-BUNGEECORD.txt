[ ] PASSO 1: BAIXAR OS 4 JARS
    [ ] BungeeCord Latest
        https://ci.md-5.net/job/BungeeCord/lastSuccessfulBuild/artifact/bootstrap/target/BungeeCord.jar
        → Salvar em: bungeecord/BungeeCord.jar
    
    [ ] Paper 1.20.6 (Auth)
        https://papermc.io/downloads/paper
        → Salvar em: auth/server.jar
    
    [ ] Paper 1.20.6 (Hub)
        https://papermc.io/downloads/paper
        → Salvar em: hub/server.jar
    
    [ ] Paper 1.20.6 (Game)
        https://papermc.io/downloads/paper
        → Salvar em: game/server.jar

[ ] PASSO 2: FAZER UPLOAD PARA A HOST
    [ ] Copiar pasta bungeecord/
    [ ] Copiar pasta auth/
    [ ] Copiar pasta hub/
    [ ] Copiar pasta game/

[ ] PASSO 3: CONFIGURAR FIREWALL
    [ ] ABRIR porta 25100 (BungeeCord)
    [ ] FECHAR porta 25578 (Hub)
    [ ] FECHAR porta 25579 (Auth)
    [ ] FECHAR porta 25580 (Game)

[ ] PASSO 4: INICIAR OS SERVIDORES NA ORDEM
    [ ] 1. Auth Server (25579) → Aguardar "Done!" (~30s)
    [ ] 2. Hub Server (25578) → Aguardar "Done!" (~30s)
    [ ] 3. Game Server (25580) → Aguardar "Done!" (~30s)
    [ ] 4. BungeeCord (25100) → Aguardar "Listening on" (~5s)

[ ] PASSO 5: COPIAR paper-global.yml (IMPORTANTE!)
    Para cada servidor (Auth, Hub, Game):
    [ ] Iniciar o servidor uma vez
    [ ] Aguardar criar a pasta config/
    [ ] Parar o servidor
    [ ] Copiar paper-global.yml para config/paper-global.yml
    [ ] Reiniciar o servidor

[ ] PASSO 6: CONFIGURAR LOCALIZAÇÕES DO GAME
    [ ] Editar: game/plugins/Game/config.yml
    [ ] Definir lobby-location
    [ ] Definir arena-location

[ ] PASSO 7: DEFINIR GAMEMASTER
    [ ] Conectar no servidor
    [ ] Executar: /r6 gm <seu_nick>

[ ] PASSO 8: TESTAR!
    [ ] Conectar em: admin.savagemc.net:25100
    [ ] Testar com jogador original
    [ ] Testar com jogador pirata
    [ ] Testar auto-join no Game
    [ ] Testar menu do Gamemaster

                              COMANDOS ÚTEIS

GAMEMASTER:
/r6 gm <player>           - Definir gamemaster
/r6 gm remove             - Remover gamemaster

GUARDAS:
/r6 guard add <player>    - Adicionar guarda
/r6 guard remove <player> - Remover guarda
/r6 guard list            - Listar guardas

JOGADORES:
/r6 join                  - Entrar no jogo (opcional)
/r6 leave                 - Sair do jogo

AUTH:
/register senha senha     - Registrar (piratas)
/login senha              - Logar (piratas)
