ERRO:
java.lang.ClassCastException: class java.lang.Boolean cannot be cast to class java.lang.String


🔧 SOLUÇÃO RÁPIDA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

O problema é que o config.yml antigo tem valores booleanos onde o BungeeCord
espera strings. Você precisa deletar o arquivo e deixar o BungeeCord gerar um novo.


📝 PASSO A PASSO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASSO 1: PARAR O BUNGEECORD
   - Pare o servidor BungeeCord

PASSO 2: DELETAR O CONFIG.YML ANTIGO
   - Acesse o painel Pterodactyl
   - Vá em Files
   - Delete o arquivo: config.yml

PASSO 3: INICIAR O BUNGEECORD
   - Inicie o servidor
   - O BungeeCord irá gerar um novo config.yml

PASSO 4: PARAR O BUNGEECORD NOVAMENTE
   - Pare o servidor

PASSO 5: EDITAR O CONFIG.YML
   - Acesse o painel Pterodactyl
   - Vá em Files
   - Edite o arquivo: config.yml
   - Cole o conteúdo abaixo

PASSO 6: INICIAR O BUNGEECORD
   - Inicie o servidor
   - Deve funcionar agora!

⚠️ IMPORTANTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. NÃO adicione comentários (#) no config.yml
2. Mantenha a indentação exata (use espaços, não tabs)
3. Valores booleanos devem ser: true ou false (sem aspas)
4. Valores de texto devem ter aspas: 'texto'
