  CORREÇÃO DO ERRO: IP FORWARDING
═══════════════════════════════════════════════════════════════

PROBLEMA:
Players sendo kickados com: "If you wish to use IP forwarding, 
please enable it in your BungeeCord config as well!"

CAUSA:
O BungeeCord estava com ip_forward: false

SOLUÇÃO APLICADA:
✓ Alterado ip_forward: true no config.yml do BungeeCord
✓ Alterado porta do listener para 25100
✓ Alterado prioridade para hub (jogadores vão primeiro pro hub)
✓ Alterado max_players para 100

═══════════════════════════════════════════════════════════════
  PASSOS PARA APLICAR NO SERVIDOR
═══════════════════════════════════════════════════════════════

1. PARAR TODOS OS SERVIDORES
   - Pare BungeeCord
   - Pare Auth, Hub e Game

2. ATUALIZAR BUNGEECORD
   - Faça upload do novo config.yml para: /bungeecord/config.yml
   - Faça upload do EventBungee.jar para: /bungeecord/plugins/EventBungee.jar

3. VERIFICAR PAPER SERVERS
   Cada servidor (Auth, Hub, Game) deve ter o arquivo:
   config/paper-global.yml
   
   Com o conteúdo:
   proxies:
     bungee-cord:
       online-mode: false

4. INICIAR SERVIDORES NA ORDEM
   a) Inicie Auth (porta 25579)
   b) Inicie Hub (porta 25578)
   c) Inicie Game (porta 25580)
   d) Inicie BungeeCord (porta 25100)

5. TESTAR CONEXÃO
   - Conecte no IP do BungeeCord na porta 25100
   - Jogadores PREMIUM vão direto pro Hub
   - Jogadores PIRATAS vão pro Auth

═══════════════════════════════════════════════════════════════
  VERIFICAÇÃO RÁPIDA
═══════════════════════════════════════════════════════════════

BungeeCord config.yml deve ter:
✓ ip_forward: true
✓ online_mode: true
✓ host: 0.0.0.0:25100

Paper servers (Auth/Hub/Game) devem ter:
✓ Arquivo: config/paper-global.yml
✓ Conteúdo: proxies.bungee-cord.online-mode: false

EventBungee.jar:
✓ Versão mais recente com detecção Mojang API
✓ Localizado em: bungeecord/plugins/EventBungee.jar
