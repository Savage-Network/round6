🚀 PASSO A PASSO DO DEPLOY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASSO 1: BAIXAR OS 5 JARS
  - Velocity 3.3.0+
  - Paper 1.20.6 (3x ou usar o mesmo)

PASSO 2: COLOCAR OS JARS NAS PASTAS
  - velocity/velocity.jar
  - auth/server.jar
  - hub/server.jar
  - game/server.jar

PASSO 3: FAZER UPLOAD PARA A HOST
  Copiar as 4 pastas mantendo a estrutura:
  - velocity/
  - auth/
  - hub/
  - game/

PASSO 4: CONFIGURAR FIREWALL
  ABRIR:  25100 (Velocity)
  FECHAR: 25578, 25579, 25580 (servidores backend)

PASSO 5: INICIAR OS SERVIDORES NA ORDEM
  1. Auth Server (25579)   → Aguardar "Done!" (~30s)
  2. Hub Server (25578)    → Aguardar "Done!" (~30s)
  3. Game Server (25580)   → Aguardar "Done!" (~30s)
  4. Velocity (25100)      → Aguardar "Listening on" (~10s)

PASSO 6: CONFIGURAR LOCALIZAÇÕES (IMPORTANTE!)
  Editar: game/plugins/Game/config.yml
  
  Definir:
  - lobby-location (onde jogadores aparecem)
  - arena-location (onde o jogo acontece)
  
  Como pegar coordenadas:
  1. Entre no servidor Game
  2. Vá para o local desejado
  3. Pressione F3 (Java) ou veja coordenadas
  4. Copie X, Y, Z, Yaw, Pitch
  5. Cole no config.yml

PASSO 7: DEFINIR GAMEMASTER
  /r6 gm <seu_nick>

PASSO 8: TESTAR!
  Conecte em: admin.savagemc.net:25100
