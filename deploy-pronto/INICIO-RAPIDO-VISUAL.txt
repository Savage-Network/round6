Inicie NA ORDEM:

1️⃣ Auth Server
   cd auth
   ./start.sh (Linux) ou start.bat (Windows)
   ⏳ Aguarde "Done!" (~30s)

2️⃣ Hub Server
   cd hub
   ./start.sh (Linux) ou start.bat (Windows)
   ⏳ Aguarde "Done!" (~30s)

3️⃣ Game Server
   cd game
   ./start.sh (Linux) ou start.bat (Windows)
   ⏳ Aguarde "Done!" (~30s)

4️⃣ Velocity
   cd velocity
   ./start.sh (Linux) ou start.bat (Windows)
   ⏳ Aguarde "Listening on" (~10s)


⚙️ PASSO 4: CONFIGURAR (30 segundos)

Entre no servidor Game e pegue as coordenadas:

📍 Lobby (onde jogadores aparecem):
   1. Vá para o local
   2. Pressione F3 (Java)
   3. Copie X, Y, Z

📍 Arena (onde o jogo acontece):
   1. Vá para o local
   2. Pressione F3 (Java)
   3. Copie X, Y, Z

Edite: game/plugins/Game/config.yml

lobby-location:
  x: [COLE AQUI]
  y: [COLE AQUI]
  z: [COLE AQUI]

arena-location:
  x: [COLE AQUI]
  y: [COLE AQUI]
  z: [COLE AQUI]

Salve e reinicie o Game Server

Gamemaster:
  /r6 gm <player>  → Definir gamemaster
  /r6 gm remove    → Remover gamemaster

Guardas:
  /r6 guard add <player>     → Adicionar guarda
  /r6 guard remove <player>  → Remover guarda
  /r6 guard list             → Listar guardas

Jogadores:
  /r6 join   → Entrar (opcional, auto-join ativo)
  /r6 leave  → Sair
