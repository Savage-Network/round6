🚀 COMO USAR:

PASSO 1: Baixar os JARs
   • Velocity 3.3.0+ → velocity/velocity.jar
   • Paper 1.20.6 → auth/paper.jar
   • Paper 1.20.6 → hub/paper.jar

PASSO 2: Copiar as pastas para a host
   • Copie as 3 pastas (velocity, auth, hub) para sua host
   • Mantenha a estrutura de pastas intacta

PASSO 3: Iniciar os servidores (NESTA ORDEM!)
   
   Windows:
   1. Execute: auth/start.bat
   2. Aguarde ~30 segundos até ver "Done!"
   3. Execute: hub/start.bat
   4. Aguarde ~30 segundos até ver "Done!"
   5. Execute: velocity/start.bat
   
   Linux:
   1. chmod +x auth/start.sh && ./auth/start.sh
   2. Aguarde ~30 segundos até ver "Done!"
   3. chmod +x hub/start.sh && ./hub/start.sh
   4. Aguarde ~30 segundos até ver "Done!"
   5. chmod +x velocity/start.sh && ./velocity/start.sh

PASSO 4: Conectar
   • IP: seu-ip:25100
   • Jogadores piratas: vão para Auth → /register senha senha
   • Jogadores originais: vão direto para Hub

🐛 PROBLEMAS?

• "Can't connect to MySQL"
  → Verifique se o host MySQL está acessível
  → Teste: ping mysql52-farm1.kinghost.net

• "Connection refused"
  → Certifique-se que Auth e Hub iniciaram ANTES do Velocity
  → Verifique se as portas 25101 e 25102 estão livres

• "Invalid forwarding secret"
  → NÃO altere nenhum arquivo de configuração!
  → O secret já está configurado corretamente

• Jogadores não redirecionam
  → Verifique logs em: velocity/logs/latest.log
  → Confirme que os 3 servidores estão rodando
