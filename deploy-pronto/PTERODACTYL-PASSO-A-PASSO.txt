O erro no final é porque falta o arquivo paper-global.yml


🔧 CORRIGIR O ERRO DE FORWARDING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASSO 1: PARAR O SERVIDOR
  - No painel Pterodactyl, clique em "Stop"
  - Aguarde o servidor parar completamente

PASSO 2: ABRIR O FILE MANAGER
  - No painel Pterodactyl, clique em "Files"
  - Você verá a lista de arquivos do servidor

PASSO 3: ENTRAR NA PASTA config
  - Clique na pasta "config"
  - Você verá vários arquivos .yml

PASSO 4: CRIAR/EDITAR paper-global.yml
  
  Opção A - Se o arquivo NÃO existe:
    1. Clique em "New File"
    2. Nome: paper-global.yml
    3. Clique em "Create"
  
  Opção B - Se o arquivo JÁ existe:
    1. Clique no arquivo "paper-global.yml"
    2. Clique em "Edit"

PASSO 5: COLAR O CONTEÚDO
  
  Apague tudo e cole isto:

  ┌─────────────────────────────────────────────────┐
  │ # Configuração Paper para Velocity              │
  │                                                  │
  │ proxies:                                         │
  │   velocity:                                      │
  │     enabled: true                                │
  │     online-mode: false                           │
  │     secret: round6secret2024                     │
  └─────────────────────────────────────────────────┘

PASSO 6: SALVAR
  - Clique em "Save Content" ou "Save File"
  - Volte para a aba "Console"

PASSO 7: INICIAR O SERVIDOR
  - Clique em "Start"
  - Aguarde "Done!"

PASSO 8: TESTAR
  - Conecte no Velocity
  - Você deve conectar sem erros!


📋 CONTEÚDO EXATO DO ARQUIVO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Copie EXATAMENTE isto (sem as linhas):

# Configuração Paper para Velocity

proxies:
  velocity:
    enabled: true
    online-mode: false
    secret: round6secret2024


⚠️ IMPORTANTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. O arquivo DEVE estar em: config/paper-global.yml
2. NÃO coloque na raiz do servidor
3. Respeite a indentação (2 espaços)
4. O secret deve ser EXATAMENTE: round6secret2024
5. Salve e reinicie o servidor
