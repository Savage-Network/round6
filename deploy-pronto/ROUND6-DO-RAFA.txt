🎮 COMANDOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

JOGADORES:
  /r6 join   - Entrar no jogo (opcional, auto-join ativo)
  /r6 leave  - Sair do jogo

GAMEMASTER:
  /r6 gm <player>  - Definir gamemaster
  /r6 gm remove    - Remover gamemaster

GUARDAS:
  /r6 guard add <player>     - Adicionar guarda
  /r6 guard remove <player>  - Remover guarda
  /r6 guard list             - Listar guardas

ADMIN:
  /r6 start  - Iniciar jogo forçado

⚙️ COMO USAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASSO 1: DEFINIR GAMEMASTER
  /r6 gm Rafa

PASSO 2: ADICIONAR GUARDAS (Opcional)
  /r6 guard add Guard1
  /r6 guard add Guard2

PASSO 3: GAMEMASTER RECEBE ITENS
  - Automaticamente ao ser definido
  - 8 itens no inventário

PASSO 4: SELECIONAR MINIGAME
  - Clique no item "Menu de Jogos"
  - Escolha um minigame

PASSO 5: INICIAR JOGO
  - Clique no item "Iniciar Jogo"
  - Jogo começa automaticamente

PASSO 6: GERENCIAR JOGO
  - Use os itens para controlar
  - Guardas podem eliminar trapaceiros
  - Gamemaster tem controle total
