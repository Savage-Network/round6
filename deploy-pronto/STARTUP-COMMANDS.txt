📦 VELOCITY (Proxy - Porta 25100)

Startup Command:
java -Xms128M -XX:MaxRAMPercentage=95.0 -jar velocity.jar

Docker Image:
ghcr.io/pterodactyl/yolks:java_21

Arquivo JAR:
velocity.jar (baixar de https://papermc.io/downloads/velocity)

╔══════════════════════════════════════════════════════════════════════════════╗
║                        COMO ALTERAR NO PTERODACTYL                           ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. Acesse o painel do servidor no Pterodactyl
2. Vá em "Startup"
3. Localize o campo "Startup Command"
4. Cole o comando correspondente ao servidor
5. Clique em "Save"

No painel do Pterodactyl, configure as portas em "Network":

╔══════════════════════════════════════════════════════════════════════════════╗
║                              ORDEM DE UPLOAD                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝

PARA CADA SERVIDOR:

1. Alterar Startup Command
2. Fazer upload do JAR principal (velocity.jar ou paper.jar)
3. Fazer upload dos arquivos de configuração
4. Fazer upload dos plugins
5. Iniciar o servidor
6. Aguardar primeira inicialização
7. Fazer upload dos configs dos plugins (se necessário)
8. Reiniciar

╔══════════════════════════════════════════════════════════════════════════════╗
║                              ERROS COMUNS                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

❌ "Unable to access jarfile server.jar"
✅ Solução: Altere o Startup Command para o nome correto do JAR

❌ "EULA not accepted"
✅ Solução: Faça upload do eula.txt com eula=true

❌ "Failed to bind to port"
✅ Solução: Verifique a porta no server.properties e no Pterodactyl

❌ "Invalid forwarding secret"
✅ Solução: Faça upload do paper-global.yml correto
