INSTRUÇÕES:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Abra o config.yml no editor do Pterodactyl

2. Encontre a seção "servers:" (deve ter apenas "lobby:")

3. SUBSTITUA toda a seção "servers:" por:

servers:
  auth:
    motd: Auth Server
    address: localhost:25579
    restricted: false
  hub:
    motd: Hub Server
    address: localhost:25578
    restricted: false
  game:
    motd: Game Server
    address: localhost:25580
    restricted: false

4. Encontre a linha "priorities:" dentro de "listeners:"

5. SUBSTITUA por:

  priorities:
  - auth

6. Salve o arquivo (Ctrl+S)

7. Reinicie o BungeeCord
