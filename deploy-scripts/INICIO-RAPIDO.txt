📋 PASSO A PASSO RÁPIDO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ OBTER API KEY DO PTERODACTYL

   a) Acesse seu painel: https://admin.savagemc.net
   b) Vá em: Account → API Credentials
   c) Clique em: Create API Key
   d) Copie a chave (começa com ptlc_)


2️⃣ OBTER IDs DOS SERVIDORES

   Para cada servidor (BungeeCord, Auth, Hub, Game):
   
   a) Acesse o servidor no painel
   b) Vá em: Settings → Debug Information
   c) Copie o Server ID (ex: d3aac109)


3️⃣ CONFIGURAR O SCRIPT

   OPÇÃO A - Configuração Automática (Recomendado):
   
   WINDOWS:
   deploy-scripts\setup-deploy.bat
   
   LINUX/MAC:
   chmod +x deploy-scripts/setup-deploy.sh
   ./deploy-scripts/setup-deploy.sh
   
   O assistente irá guiá-lo pela configuração!
   
   
   OPÇÃO B - Configuração Manual:
   
   Edite o arquivo:
   - Windows: deploy-scripts\deploy-pterodactyl.bat
   - Python: deploy-scripts/deploy-pterodactyl.py
   - Bash: deploy-scripts/deploy-pterodactyl.sh
   
   Configure:
   - PANEL_URL = "https://admin.savagemc.net"
   - API_KEY = "ptlc_sua_chave_aqui"
   - SERVERS = { ... IDs dos servidores ... }


4️⃣ INSTALAR DEPENDÊNCIAS (apenas Python)

   pip install requests


5️⃣ EXECUTAR O DEPLOY

   WINDOWS:
   deploy-scripts\deploy-pterodactyl.bat
   
   PYTHON:
   python3 deploy-scripts/deploy-pterodactyl.py
   
   BASH:
   ./deploy-scripts/deploy-pterodactyl.sh


6️⃣ REINICIAR SERVIDORES

   Após o deploy, reinicie os servidores no painel Pterodactyl

🐛 PROBLEMAS COMUNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Erro: "401 Unauthorized"
   → API Key inválida ou expirada
   → Gere uma nova API Key no painel

❌ Erro: "404 Not Found"
   → Server ID incorreto
   → Verifique os IDs em Settings → Debug Information

❌ Erro: "File too large"
   → Arquivo maior que 100 MB
   → Pterodactyl limita uploads a 100 MB

❌ Erro: "Connection refused"
   → URL do painel incorreta
   → Verifique se o painel está online
